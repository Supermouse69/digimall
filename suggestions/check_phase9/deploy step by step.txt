STEP 2: A ".env.production" FILE ON YOUR PC (never committed: .env* is gitignored)
==================================================================
 [ ] 2.1 Copy .env.example to .env.production and fill in PRODUCTION values:
         - DATABASE_URI = the digimall-prod string (step 1.3)
         - PAYLOAD_SECRET = NEW long random value:
             node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
           (NOT the dev one. Changing it later breaks 2FA, so keep it forever)
         - ADMIN_ENTRY_PATH = NEW long random value (same command, 24 bytes)
         - CRON_SECRET = NEW long random value
         - NEXT_PUBLIC_VAPID_PUBLIC_KEY / VAPID_PRIVATE_KEY = a NEW pair:
             node -e "console.log(require('web-push').generateVAPIDKeys())"
         - NEXT_PUBLIC_APP_URL=https://digimall.online   NEXT_PUBLIC_ROOT_DOMAIN=digimall.online
         - NEXT_PUBLIC_ENABLE_SUBDOMAIN_ROUTING=false
         - Turnstile / R2 / Blob / Resend values from the steps below
 [ ] 2.2 Run the migrations on the PRODUCTION database (creates the legal page placeholders + settings):
             bun run prod:migrate
 [ ] 2.3 Create YOUR super-admin there (password shown once):
             bun run prod:create-admin -- you@yourmail.com "Your Name"
